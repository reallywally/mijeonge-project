# 미정이 프로젝트

## 개요

- 정해야 할 것(안건)과 그 결정 · 미룸 기록을 문서가 아닌 시스템에 등록하여 관리한다.
- 지라 같은 일정 관리 기능(작업)과 연결해 작업과 관련된 결정 내용을 확인한다.



## 만들게된 계기

- 회의는 했는데 아무것도 결정 못하고, 서로 미루고, 책임 회피하는걸 방지하고 싶었다.
- 회의록을 남겨도 문서로 남기니 기록을 찾기 어려웠다. DB화 하고 AI Agent 붙이면 좋을것 같다.



## 핵심 컨셉, 기능

- 회의를 따로 관리하지 않는다. **정해야 할 것(안건)을 등록하고, 결정 · 미룸을 안건에 기록**한다.
- AI로 여러 작업을 한다.
  - 땡땡 기능 개발할때 보안 수준 어떻게 하기로 햇지? 
  - 등록된 안건을 정하려면 어떤 부분을 체크해야하는지 알려줘



### 개발환경

- 프론트: vue
- 백: fastapi
- db: postgresql 또는 supabase
