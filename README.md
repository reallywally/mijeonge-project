# 미정이 프로젝트

## 개요

- 회의록을 문서가 아닌 시스템에 등록하여 관리한다.
- 추후 지라 같은 일정 관리 기능도 추가하여 일정(작업)과 관련 회의 내용을 확인하다.



## 만들게된 계기

- 회의는 했는데 아무것도 결정 못하고, 서로 미루고, 책임 회피하는걸 방지하고 싶었다.
- 회의록을 남겨도 문서로 남기니 기록을 찾기 어려웠다. DB화 하고 AI Agent 붙이면 좋을것 같다.



## 핵심 컨셉, 기능

- 회의를 시작하고 뭘 할지 결정하는게 아니라 **뭘 할지(안건) 먼저 결정하고 회의**한다. 
- AI로 여러 작업을 한다.
  - 땡땡 기능 개발할때 보안 수준 어떻게 하기로 햇지? 
  - 등록된 안건으로 회의를 할려고 하는데 어떤 부분을 체크해야하는지 알려줘
- 회의 참석자에게 메일을 보낸다.
